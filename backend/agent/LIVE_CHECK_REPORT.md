# Проверка агента с NVIDIA — 23 октября 2026

Исторический отчёт о прежнем провайдере. Агент переведён на DeepSeek через API Mira;
актуальная успешная проверка: [APIMIRA_CHECK_REPORT.md](APIMIRA_CHECK_REPORT.md).

**Результат: локальная логика проходит тесты; успешная генерация через NVIDIA
не подтверждена. Реальные POST-запросы завершаются таймаутом.**

Проверка выполнена с ключом из `backend/agent/.env`, моделью
`z-ai/glm-5.3-flash`, без fallback на mock. Значение ключа, заголовки
авторизации и содержимое рассуждений не выводились и не сохранялись в отчёт.
GitHub и другие ветки не изменялись.

## Что проверено

| Проверка | Результат |
|---|---|
| Unit-тесты загрузки конфигурации, ранжирования, JSON, ссылок, trace, HTTP-ошибок и fallback | 47 из 47 прошли, повторно после правки настроек |
| DNS `integrate.api.nvidia.com` | Успешно, 0.08 с |
| Соединение TCP/TLS | Успешно, TLS 1.3, 0.16 с |
| `GET /v1/models` с настроенным заголовком авторизации | HTTP 200, 0.22 с; выбранная модель есть в списке |
| Агент: восемь новостей первой компании, timeout=60 | `LLMTransportError`, таймаут через 60.20 с |
| Короткий контрольный запрос «Reply with only OK.», max_tokens=128, reasoning_effort=low | `TimeoutError` через 45.16 с |
| Повтор агента: восемь новостей, timeout=180, reasoning_effort=low | `LLMTransportError`, таймаут через 180.23 с |
| POST с заведомо невалидным max_tokens=0, без ожидаемой генерации | `TimeoutError` через 15.17 с; HTTP-статус не получен |

Во время реального запуска не получен ни один итоговый insight. Переход ко второй
компании остановлен после ошибки первой. Расход токенов от API не получен.
Различия интерпретаций, JSON и содержание результатов реальной модели проверить
не удалось. Unit-тесты используют подменённый HTTP и не доказывают работу LLM.

`GET /v1/models` подтверждает доступность каталога, но сам по себе не доказывает
разрешение ключа на генерацию. Ответа 401/403 также не было. Нельзя утверждать,
что ключ неверен или что причина только во времени рассуждений: таймаутом
заканчивается даже короткий POST для проверки валидации. Сбой локализован до
вызова chat completions; точная причина на стороне маршрута/сервиса или доступа
к нему пока не установлена.

## Локальные изменения

- Таймаут по умолчанию увеличен с 60 до 180 секунд.
- Добавлен явный `AGENT_LLM_REASONING_EFFORT=low` и проверка допустимых значений
  `low`, `high`, `max`. Параметр описан в
  [карточке NVIDIA](https://docs.api.nvidia.com/nim/reference/z-ai-glm-5-3-flash).
- Ключ в `.env` сохранён; обновлены шаблон и документация.
- Mock-fallback при реальных проверках выключен. Автоматических повторов нет.

Эти изменения **не устранили таймаут** и не выдаются за успешное подключение.
Нужна повторная проверка chat completions при доступном POST endpoint, при
необходимости из другой сети или через NVIDIA Build с тем же ключом.

## Воспроизведение

Из корня проекта, в Python-окружении с зависимостями агента:

```powershell
python -m unittest discover -s tests -v
python -m backend.agent.examples --mode llm --output tmp/agent-day2-llm.json
```

Не добавлять `--fallback-mock` при проверке подключения. Критерий успеха — два
валидных результата с `mode=llm`, `model=GLM-5.3-Flash`,
`trace.provider_model=z-ai/glm-5.3-flash`, `is_mock=false` во всех элементах,
разными интерпретациями общей новости и `bank_view=null` при пустых банковских
источниках. Локальные диагностические JSON находятся в `tmp/agent-live-check/`
и игнорируются Git.
