## Одна новость, разные компании

Новость `demo-news-rate` — учебное сохранение ключевой ставки:

| Компания | Оценка | Смысл интерпретации |
|---|---:|---|
| Промышленная, есть кредиты, долг/выручка 0.60 | 50, high | Возможное влияние на обслуживание долга и новые заимствования, только если условия связаны с ключевой ставкой; такой связи профиль не подтверждает |
| Торговая, есть депозиты, кредитов нет | 25, medium | Значение для условий депозитов; действующие договоры требуют отдельной проверки |

`impact` и `why_relevant` различаются. При ручном просмотре тексты сохраняют
условность последствий, не задают неизвестное направление курса или спроса и
не приписывают банку мнение. Это проверка на двух синтетических профилях,
а не полноценная оценка качества на реальных данных. Численные оценки
рассчитываются локальным ranker, а не моделью.

## Воспроизведение

Из корня проекта, с установленными зависимостями и ключом в локальном `.env`:

```powershell
python -m unittest discover -s tests -v
python -m backend.agent.examples --mode llm --output tmp/agent-day2-llm.json
```

`response_format` не передаётся: [документация API Mira](https://apimira.com/docs)
указывает, что шлюз отклоняет его. JSON запрашивается в prompt и проверяется
локально. Параметр NVIDIA `reasoning_effort` также убран из конфигурации адаптера.
Автоматических повторов и скрытой смены модели нет.

Веб-интерфейс, HTTP endpoint Backend для генерации, Retrieval и автономная
самопроверка этим изменением не добавлялись. GitHub и другие ветки не изменялись.
